# **Touch-Activated LED Birthday Card**

### **Aim**

To design a simple and interactive birthday greeting card using an LED, coin battery, and aluminium tape.

### **Components**

* LED  
* coin battery V-3  
* Aluminium tape  
* Greeting card

### **Working**

The LED is connected to the 3 V coin battery using aluminium tape. When the user touches the aluminium tape touch area, the electrical connection is completed and the LED glows.

### **Application**

* Interactive birthday greeting cards  
* Handmade electronic gifts  
* Decorative greeting cards  
* Creative event card
